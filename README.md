# Local Wiki Explorer

A web app for exploring and contributing to local knowledge bases.

## Trend

Local Wikipedia: Wikipedia, but only for things a half hour walk from you

## Users

Community contributors and curious locals

## Setup

```bash
npm install
npm test
npm run build
npm start   # http://127.0.0.1:8787/
```

## Stop

Ctrl+C
